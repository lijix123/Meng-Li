# 🎴 jm下载姬

> 一个为 AstrBot 打造的禁漫本子下载插件。装上就能用，卸了就清净。

> ⭐ **本插件改编自 [hect0x7/JMComic-Crawler-Python](https://github.com/hect0x7/JMComic-Crawler-Python)**，在此向原作者致以诚挚感谢。

---
## 简介

**jm下载姬** 让你在 QQ 里直接完成禁漫本子的搜索、查看榜单、下载与交付，全程无需打开网页。

- 关键词搜索本子，分页浏览
- 日榜 / 周榜 / 月榜 Top10 一键查看
- 下载后按你的口味交付：**长图 / ZIP 压缩包 / PDF 文档**
- 交付完自动清理服务器文件，不占磁盘
- 依赖完全自包含，装上即用，卸载即净
- 自动跟随上游更新，禁漫接口变动后无需手动升级插件

## ⚠️ 已知限制与反馈

本插件目前**并不完善**，可能存在未知 bug 或兼容性问题，请知悉：

- 依赖第三方网站，禁漫接口变动期间可能出现搜索/下载异常，自动更新机制会尽力跟进但无法保证即时恢复。
- 部分本子需要登录账号才能访问，插件暂不支持登录，此类本子会下载失败（属正常现象）。

## 安装与拉取

### 从 GitHub 拉取插件

方式一：克隆整个仓库（最简单，推荐）：

```bash
git clone git@github.com:lijix123/Meng-Li.git
# 插件在 Meng-Li/astrbot_plugin_jmcomic/
```

方式二：只拉取插件目录（稀疏检出，省流量）：

```bash
git clone --depth 1 --filter=blob:none --sparse git@github.com:lijix123/Meng-Li.git
cd Meng-Li
git sparse-checkout set astrbot_plugin_jmcomic
```

方式三：直接下载仓库 ZIP：
GitHub 仓库首页 → 绿色 `Code` 按钮 → `Download ZIP`，解压后取 `astrbot_plugin_jmcomic` 文件夹。

### 安装到 AstrBot

将 `astrbot_plugin_jmcomic` 整个文件夹放入 AstrBot 的插件目录（通常是 `<AstrBot>/data/plugins/`），然后在 AstrBot 管理后台启用插件即可。

### 依赖说明与手动安装

插件依赖分两部分：

1. **jmcomic 库**：已内嵌在插件 `vendor/` 目录中，无需手动安装，随插件自带。
2. **curl-cffi（加密通信组件）**：首次加载插件时会自动安装到插件私有目录 `.deps/`，一般无需干预。

若自动安装失败（网络问题等），可手动安装：

```bash
# 进入插件目录后执行（请把 <插件路径> 换成实际路径）
pip install curl-cffi --target <插件路径>/.deps -i https://pypi.tuna.tsinghua.edu.cn/simple/
```

装完重启 AstrBot 或重载插件即可。依赖全部装在插件私有目录内，不污染系统 Python 环境，卸载插件时自动清理。

## 快速开始

装好插件后，在 QQ 里直接发消息即可（默认仅管理员可用，可在面板调整）。

| 命令 | 说明 | 示例 |
| --- | --- | --- |
| `搜本 <关键词> [页码]` | 搜索本子，每页 5 条 | `搜本 无望菜志` |
| `排行 [周/日/月]` | 查看对应榜单 Top10 | `排行 周` |
| `下本 <ID> [格式]` | 下载本子，格式支持 `长图` `zip` `pdf` | `下本 243484 长图` |
| `我的任务` | 查看自己的下载任务状态 | `我的任务` |
| `取消 <任务号>` | 取消自己的任务 | `取消 1` |

> 格式缺省时使用面板默认格式，默认 `长图`。

### 交付格式说明

- **长图**：整本拼接成一张竖图直接发到 QQ，长本自动分段发送，看着最方便。
- **ZIP**：原始高清图片打包，适合收藏存档。
- **PDF**：整本合成 PDF 文档，适合存书架。

## 自动更新

插件默认开启**自动跟随上游**：

- 插件启动时检查一次上游 jmcomic 版本，运行中每小时再检查一次。
- 发现新版：自动下载 → 校验通过 → 覆盖内置版本，只保留一份最新版。
- 更新失败：自动回退旧版，插件功能不受影响，并在下次使用命令时提醒。
- 更新成功：下次使用命令时提醒一次"已更新至 vX.X.X"。
- 版本检查走 PyPI 官方接口 + 清华镜像双源兜底，纯代码请求，不消耗任何 AI token。
- 可在面板关闭：`自动跟随上游更新` 设为 off。

> 上游库由 hect0x7/JMComic-Crawler-Python 提供，自动更新逻辑仅同步该库源码，不引入其他代码。

## 常见问题

**Q：提示"加密扩展还在装"？**
A：首次加载插件会自动安装私有加密组件，等几秒再试即可。

**Q：下载失败/搜索失败？**
A：禁漫接口偶发波动，稍后重试；也可检查服务器网络。

**Q：服务器会不会被下载堆满？**
A：不会。交付完成后服务器上的文件立即删除。
