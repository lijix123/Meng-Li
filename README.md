## 📦 插件

### 🎴 jm下载姬 `astrbot_plugin_jmcomic`

禁漫本子一键下载的 AstrBot 插件，在 QQ 里直接搜本、看榜、下载。

- 关键词搜索本子，分页浏览
- 日榜 / 周榜 / 月榜 Top10
- 长图 / ZIP / PDF 三种交付格式，长图自动分段
- 下载任务可查可取消，交付后自动清理服务器文件
- 依赖完全自包含，装上即用，卸载即净
- 自动跟随上游更新，禁漫接口变动无需手动升级
