## 部署说明

本仓库为备份与归档用途，所有真实地址、端口、Token、密钥、账号均以占位符替代，未包含任何线上凭据，可安全本地部署。

| 占位符 | 含义 | 部署时替换为 |
|--------|------|--------------|
| `<服务器IP>` | 服务端公网地址 | 实际公网 IP |
| `<服务器内网IP>` | 内网地址 | 实际内网 IP |
| `<电脑内网IP>` | 电脑内网地址 | 实际内网 IP |
| `<SSH端口>` | 服务器 SSH 端口 | 实际端口 |
| `<璃光Token>` | 璃光服务端认证 Token | 实际 Token |
| `<APIKey>` | 生图视觉校验 API Key | 实际 Key |
| `<版本号>` | APK 版本号 | 实际版本号 |
| `<姐姐UID>` / `<梦璃QQ>` | 账号标识 | 实际账号 |
| `<姐姐昵称>` | 昵称 | 实际昵称 |
| `<服务器用户>` / `<电脑用户>` | SSH 用户名 | 实际用户名 |
| `<密钥目录>` | SSH 密钥存放路径 | 实际路径 |
| `<服务器数据目录>` / `<插件数据目录>` | 数据存放路径 | 实际路径 |

- server.py 的认证 Token 从环境变量 `LIGUANG_TOKEN` 读取，部署时注入，勿硬编码。
- render.py 的视觉校验 Key 从环境变量 `SILICONFLOW_KEY` 读取，部署时注入，勿硬编码。
- App 的默认服务器地址与 Token 在 `Cfg.kt` 中为占位符，编译前替换，或运行时在 App 内填写。
- APK 安装包不归档，需要时向仓库主人索取。

如需真实凭据，向仓库主人索取。
